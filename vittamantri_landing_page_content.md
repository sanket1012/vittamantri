# Logo Direction

## Recommended Concept: “वि” Household Monogram

Create a minimal geometric logo using **वि**, derived from the opening of **वित्तमंत्री**.

The Devanagari headline stroke can subtly resemble the roof of a home while the lower letterform forms the recognizable symbol.

### Meaning

**वि + household + financial organization**

### Why it works

- Distinctive Indian identity
- Directly tied to the product name
- Works without a generic ₹ symbol
- Suitable for web favicon
- Suitable for Telegram bot profile image
- Suitable for mobile app icon later
- Can scale down cleanly
- Memorable as a standalone mark

### Visual style

- Geometric
- Rounded but not playful
- Minimal
- Solid shapes
- No gradients required
- Strong silhouette
- Modern Devanagari influence

- Credit cards

# Typography Direction

The visual system should combine a strong Devanagari typeface with a clean modern Latin typeface.

## Devanagari

Prefer:

- Clean
- Contemporary
- Highly legible
- Medium-to-bold weight for the wordmark

## Latin / UI

Use a neutral modern sans-serif.

Suitable style references:

- Inter-like
- Manrope-like
- Geist-like
- DM Sans-like

Do not make the interface overly decorative.

# Visual Design Direction

The website should feel more like a modern household product than a financial institution.

## Recommended characteristics

- Large whitespace
- Warm neutral background
- Rounded cards
- Clean charts
- Simple illustrations
- Subtle Indian identity
- Large financial numbers
- Friendly microcopy
- Minimal navigation
- Mobile-first transaction examples

## Avoid

- Corporate banking layouts
- Heavy dark dashboards
- Neon fintech colors
- Excessive gradients
- Glassmorphism everywhere
- Dense accounting tables on the landing page
- Too many financial charts above the fold
